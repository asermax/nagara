## Annotation 2 (lines 11–16)
Comment on: "The math delimiter (annotation 3).** Some articles write formulas as MathML. That's the markup a browser draws as a formula, and it carries the LaTeX source in an `alttext` attribute, e.g. `O(n^2)`. The recipe swaps the MathML for that LaTeX text. Nothing tells the recipe whether to wrap the LaTeX in `$…$`, the usual marker for "this is math", so each recipe picks: - The round 0 recipe wrote `The cost is O(n^2) here`. - The round 2 recipe wrote `The cost is $O(n^2)$ here`. `$` lets a future web player find the formula and draw it. But `to_spoken` doesn't know `$` is a marker, so the spoken form keeps it. I ran the real code: `'The cost is $O(n^2)$ here'`. The listener would hear the dollar signs, or silence where they are, followed by LaTeX read as characters. The question was whether the recipe contract should fix one form. The Formulas read aloud milestone already covers turning LaTeX into speech, so this overlaps with it."
> we should indicate in the prompt to not include any math delimiter; we can add these when we work on formulas in particular
