**Deploy order:**
1. Deploy tts to Modal: `uv run modal deploy app.py` in `tts/`. This replaces the deployed `nagara-tts` app.

3. Deploy the pipeline: `pnpm build`, then `wrangler deploy -c dist/nagara/wrangler.json`, i.e. `pnpm run deploy` in `pipeline/`. Note that `pnpm deploy` is pnpm's built-in command and must not be used.
