# Tasks

The tracker, the tools that reach it, and the task states are declared in `implement.md`.

- Ground every task in the docs: its description cites the notes that carry its design by path. A note never links back to an issue; the issue closes and the link rots.
- A `Spike` task is throwaway code written to answer a question; it never merges.
- Implementation tasks under one feature land on its `feat/<feature-name>` branch, one branch per feature.
