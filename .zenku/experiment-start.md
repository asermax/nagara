# experiment-start — Nagara project extension

Additive steps for `zenku:experiment-start`. Fold these into the base flow; they never waive its core
discipline.

## Fold into step 2 (Interview → Judging / pre-registration)

**Pre-register a synthetic probe for what the real artifact can't reach.** When the real work artifact
can't exercise a load-bearing disproof condition — a fixture that happens not to contain the hostile
case, a dataset missing the edge the hypothesis hinges on — that condition is unfalsifiable as written,
and a criterion that can't fail proves nothing. Pre-register a **minimal synthetic probe** built to
trigger exactly that case, and mark it explicitly as separate from the real-artifact judgment: the real
data still owns the verdict; the probe only keeps the disproof honest. Say plainly what the probe covers
(often strip/transform-level only) and what stays deferred (e.g. the end-to-end round-trip) so the scope
doesn't silently narrow. Reach for this only when the real artifact genuinely can't reach the case —
never as a substitute for real data.

*Provenance: learned in [experiment 002](../experiments/002-markdown-paragraphs/README.md), where the
clean-HTML fixture contained no code blocks or blockquotes and a mandatory synthetic snippet caught a
blockquote-strip bug the real article never could.*
